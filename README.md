This repository aims to make a consistent workflow on how to cover agentic ai from scratch with no frameworks and then after encountering the scracth build the next aim will be to build the agent with the help of the frame works 
For example below is the brief of the work flow that was followed while learning the agentic AI 
| Stage | Build | Main concept |
|---|---|---|
|**1**| LLM | Generation |
|**2** | Tool calling | External capabilities |
|**3** | Agent loop | Dynamic tool selection |
|**4** | RAG | External knowledge |
| **5** | Sequential workflow | Fixed execution |
| **6** | Conditional workflow | Branching |
| **7** | Parallel workflow | Concurrent tasks |
| **8** | Retry/verification workflow | Reliability |
| **9** | State | Shared workflow context |
| **10** | Orchestrator | Route tasks |
| **11** | Graph workflow | Nodes + edges |
| **12** | Build graph yourself | Understand orchestration |
| **13** | LangGraph | Framework implementation |
| **14** | LangGraph + RAG | Production-style agent |
| **15** | LangGraph + memory | Persistent agent |
| **16** | Multi-agent orchestration | Multiple specialized agents |
